# Roadmap

## Next priorities

- Validate discovery, refresh, capture, and container networking on target hosts.
- Edit switch/input settings with capability checks, a capture before writes, and
  readback. Verify momentary and toggle controls on hardware.
- Add manual and scheduled issue reports with per-device results, configurable
  timing, and checks for drift, connectivity, authentication, and faults.
- Encrypt stored credentials with a deployment key. Keep them out of snapshots
  and logs. Test password rotation on one device through its UI, Shellyficator,
  and Home Assistant. Track partial failures.
- Add saved refresh intervals, access-point/timer status, and settings filters.

## Longer-term ideas

Selected configuration restores, profiles, network/MQTT settings, scripts,
schedules, webhooks, Wi-Fi provisioning, and repeatable notifications.

See [Contributing](../../CONTRIBUTING.md) for proposing a larger change.
