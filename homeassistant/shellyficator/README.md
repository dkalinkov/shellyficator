# Shellyficator

Know what changed on your Shelly devices.

Shellyficator discovers Shelly Gen2+ devices on your network, keeps an inventory
with rooms, tags, and notes, and warns when a device's configuration differs from
a baseline you approved. It can also install firmware updates with confirmation
and verification.

This app is experimental. It opens inside Home Assistant, which signs you in.
See the Documentation tab after installing, and the
[project page](https://github.com/dkalinkov/shellyficator).
